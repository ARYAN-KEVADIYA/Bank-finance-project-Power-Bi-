# 💰 Bank Financial Performance & Customer Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Power BI Financial Analytics Dashboard** designed to analyze financial transactions, customer behavior, revenue, loans, and branch-level performance.

The dashboard provides a clear view of financial performance and helps identify important trends across **cities, branches, customers, transaction types, gender, and time periods**.

---

## 🎯 Project Objectives

* Analyze overall financial performance
* Track total transaction amounts and revenue
* Analyze deposits, withdrawals, transfers, and loans
* Understand customer transaction behavior
* Identify top customers by transactions and revenue
* Analyze loan performance across cities and branches
* Compare financial activity by gender
* Monitor monthly and yearly loan trends
* Provide an interactive and easy-to-understand financial overview

---

## 📌 Dashboard Pages

### 1. Financial Performance Dashboard

Key analysis includes:

* Total Amount
* Loan Amount
* Withdrawal Amount
* Deposit Revenue
* Transfer Amount
* Previous Month Revenue
* Previous Month Withdrawal
* Previous Month Amount
* Transactions by Type
* Transactions by City
* Product-wise Online Transactions

The dashboard shows a total amount of approximately **$2.50B**, loan amount of **₹601.5M**, deposit revenue of **₹620.2M**, and transfer amount of **₹649M**.

---

### 2. Customer Information Dashboard

This page focuses on customer-level analysis.

### Key KPIs

* Total Customers
* Total Transactions
* Revenue per Customer
* Top Customer
* Customer Transactions by City
* Transactions by Gender
* Customer-wise Transactions
* Customer-wise Revenue
* Customer Age Analysis

The dashboard also identifies individual customers with their transaction counts and revenue contribution.

---

### 3. Loan Information Dashboard

This page analyzes loan performance across different dimensions.

### Key Analysis

* Total Loan Amount
* Outstanding Loan
* Loan %
* Loan Amount by Month & Year
* Loan Amount by City
* Loan Amount by Gender
* Loan Amount by Branch
* Branch-level loan comparison

The dashboard reports a total loan amount of approximately **₹601.5M** and a loan percentage of **24.06%**.

---

## 📈 Key Insights

* Surat shows strong transaction and loan activity compared with other cities.
* Financial transactions are distributed across Transfer, Deposit, Withdrawal, and Loan categories.
* Female customers account for approximately **52.13%** of transactions, while male customers account for approximately **47.87%**.
* Customer-level analysis helps identify high-value customers based on transaction count and revenue.
* Loan performance varies significantly across cities and branches.
* Monthly and yearly analysis helps identify changes in loan activity over time.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Refresh the dataset if required.
4. Use the slicers and filters to explore the dashboard.
5. Navigate between the Financial Performance, Customer Information, and Loan Information pages.
